# ระบบร้านอาหาร

ใช้บน iPad ผ่าน Safari ได้เลย และเปิดใช้บน **Cloudflare แบบฟรี**

## ทำอะไรได้แล้ว

**หน้าร้าน (ส่วนที่ 2)**
- **ผังโต๊ะ:** เห็นทุกโต๊ะในหน้าเดียว โต๊ะที่มีลูกค้าแสดงแพ็กเกจ จำนวนคน จำนวนรอบที่สั่ง และเวลาที่เหลือ (นับถอยหลังทุกวินาที) ใกล้หมดเวลาเป็นสีส้ม เกินเวลาเป็นสีแดง
- **เปิดโต๊ะ:** เลือกแพ็กเกจหรือ "สั่งตามเมนู" (ไม่ใช่บุฟเฟต์) ใส่จำนวนผู้ใหญ่/เด็ก ระบบคำนวณค่าบุฟเฟต์และเริ่มจับเวลา
- **สั่งอาหาร:** สลับ "ในแพ็กเกจ" กับ "สั่งเพิ่ม (คิดเงินแยก)" แตะ + ที่รูปอาหาร ใส่หมายเหตุรายจานได้ ระบบกันไม่ให้สั่งเกินจำนวนจานต่อรอบ สั่งของที่หมด หรือสั่งของนอกแพ็กเกจแบบฟรี
- **จอออเดอร์ (ครัว):** ออเดอร์ใหม่ → กำลังทำ → พร้อมเสิร์ฟ → เสิร์ฟแล้ว แสดงชัดว่ารายการไหน "สั่งเพิ่ม" และมีหมายเหตุอะไร
- **คิดเงิน / ปิดโต๊ะ:** สรุปค่าบุฟเฟต์ + รายการสั่งเพิ่ม ใส่ค่าปรับหรือส่วนลดได้ เลือกวิธีจ่าย (เงินสด PromptPay โอน อื่น ๆ) แล้วปิดโต๊ะ
- ยกเลิกรอบที่สั่งผิด หรือยกเลิกการเปิดโต๊ะที่เปิดผิด (ก่อนสั่งอาหาร) ได้

**ตั้งค่าร้าน (ส่วนที่ 1)**
- **เมนู:** เพิ่ม แก้ ลบ **ใส่รูปได้** (ระบบย่อรูปให้อัตโนมัติ) ตั้งราคาสั่งเพิ่ม สลับ "พร้อมขาย / หมด" เลือกว่าอยู่ในแพ็กเกจไหน
- **แพ็กเกจ:** ราคาผู้ใหญ่/เด็ก เวลาทาน จำนวนจานต่อรอบ รายการอาหารในแพ็กเกจ
- **ตั้งค่าโต๊ะ:** เพิ่มทีละโต๊ะหรือหลายโต๊ะพร้อมกัน (ลบโต๊ะที่มีลูกค้าอยู่ไม่ได้)
- **รหัส PIN** กันคนนอก กรอกผิด 5 ครั้งล็อก 5 นาที

**ส่วนถัดไป:** พิมพ์ใบสั่งเข้าครัว, QR PromptPay, รายงานยอดขาย, บอท LINE OA

> หลายเครื่องใช้พร้อมกันได้ (เช่น iPad หน้าร้าน + แท็บเล็ตในครัว) หน้าผังโต๊ะและจอออเดอร์อัปเดตเองทุก 15 วินาที

## อัปเดตจากเวอร์ชันก่อน

ใน GitHub ไปที่ **Add file → Upload files** แล้วลากไฟล์และโฟลเดอร์ทั้งหมดจาก zip ชุดนี้ไปวาง (`src`, `public`, `test`, `README.md` ฯลฯ) → **Commit changes**
Cloudflare จะ deploy ใหม่ให้เองภายในไม่กี่นาที ข้อมูลเมนู แพ็กเกจ โต๊ะ และรูปเดิมยังอยู่ครบ ระบบจะสร้างตารางใหม่สำหรับออเดอร์ให้อัตโนมัติ

---

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|---|---|
| `src/worker.js` | เซิร์ฟเวอร์หลัก + ตั้งค่าร้าน |
| `src/service.js` | เปิดโต๊ะ สั่งอาหาร ครัว คิดเงิน |
| `src/lib.js` | ตัวช่วยที่ใช้ร่วมกัน |
| `public/` | หน้าจอที่เปิดบน iPad |
| `wrangler.toml` | ตั้งค่าสำหรับ Cloudflare |
| `test/` | ชุดทดสอบ (ไม่ได้ใช้ตอนเปิดร้านจริง) |

## ติดตั้งครั้งแรก

### ขั้นที่ 1: อัปเดตโค้ดใน GitHub

ชุดนี้เปลี่ยนจากเวอร์ชันก่อนหน้า ให้ทำดังนี้

1. เปิด repository `restaurant-system` ใน GitHub
2. **ลบไฟล์เก่าที่ไม่ใช้แล้ว:** คลิกไฟล์ `server.js` → กดปุ่ม `…` มุมขวาบน → **Delete file** → **Commit changes**
3. **อัปโหลดไฟล์ใหม่:** กลับไปหน้าแรกของ repo → **Add file → Upload files** → ลากไฟล์และโฟลเดอร์ทั้งหมดในโฟลเดอร์ `restaurant-system` ที่แตก zip แล้ว (`src`, `public`, `test`, `wrangler.toml`, `package.json`, `README.md`) → **Commit changes**

ไฟล์ชื่อเดิมจะถูกแทนที่ด้วยเวอร์ชันใหม่ให้เอง

### ขั้นที่ 2: เปิดใช้งานบน Cloudflare (ฟรี)

1. สมัครบัญชีที่ **dash.cloudflare.com** (แพ็กเกจฟรี)
2. ไปที่ **Workers & Pages** → **Create application** → กด **Get started** ตรง **Import a repository**
3. เชื่อมบัญชี GitHub แล้วเลือก repo `restaurant-system`
4. ตั้งชื่อโปรเจกต์เป็น **`restaurant-system`** (ต้องตรงกับชื่อใน `wrangler.toml` ไม่อย่างนั้นจะ deploy ไม่ผ่าน) คำสั่ง deploy ใช้ค่าเริ่มต้น `npx wrangler deploy` ได้เลย
5. กด **Save and Deploy** แล้วรอจนขึ้นว่าสำเร็จ
   - Cloudflare จะสร้างฐานข้อมูล D1 ชื่อ `restaurant-db` ให้อัตโนมัติ และระบบจะสร้างตารางเองตอนเปิดใช้ครั้งแรก
6. **ตั้งรหัส PIN:** เปิด Worker `restaurant-system` → **Settings** → **Variables and Secrets** → **Add**
   - Type: **Secret**
   - Name: `ADMIN_PIN`
   - Value: รหัสของร้าน **อย่างน้อย 6 หลัก**
   - กดบันทึก/Deploy
7. เปิดลิงก์ที่ลงท้ายด้วย `.workers.dev` บน iPad → ใส่ PIN

**ทำให้เหมือนแอปบน iPad:** เปิดลิงก์ใน Safari → กดปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**

### ถ้า deploy ไม่ผ่านเพราะเรื่องฐานข้อมูล (database)

การสร้างฐานข้อมูลอัตโนมัติยังเป็นฟีเจอร์ทดลองของ Cloudflare ถ้าไม่ผ่าน ให้สร้างเอง:

1. ในหน้า Cloudflare ไปที่ **Storage & Databases → D1** → **Create database** → ตั้งชื่อ `restaurant-db`
2. คัดลอก **Database ID** ที่ได้
3. ใน GitHub เปิดไฟล์ `wrangler.toml` → กดรูปดินสอเพื่อแก้ → เพิ่มบรรทัดนี้ใต้ `database_name = "restaurant-db"`
   ```toml
   database_id = "วาง-ID-ที่คัดลอกมา"
   ```
4. กด **Commit changes** แล้ว Cloudflare จะ deploy ใหม่ให้เอง

## ทุกครั้งที่ได้โค้ดเวอร์ชันใหม่

อัปโหลดไฟล์ที่เปลี่ยนไปทับใน GitHub แบบเดิม Cloudflare จะอัปเดตเว็บให้อัตโนมัติ ข้อมูลร้าน (เมนู รูป โต๊ะ) อยู่ในฐานข้อมูล D1 ไม่หาย

## ข้อจำกัดของแพ็กเกจฟรี

ฐานข้อมูล D1 แบบฟรี อ่านได้วันละ 5 ล้านแถว เขียนได้วันละ 100,000 แถว เก็บได้ 5 GB ร้านอาหารหนึ่งร้านใช้ไม่ถึง ถ้าเกิน ระบบจะใช้ไม่ได้ชั่วคราวจนถึง 7 โมงเช้า (เวลาไทย) แต่ข้อมูลไม่หาย

รูปเมนูถูกย่อเหลือประมาณ 10–100 KB ต่อรูป เก็บได้หลายหมื่นรูป

หน้าผังโต๊ะและจอออเดอร์ดึงข้อมูลใหม่ทุก 15 วินาที เฉพาะตอนเปิดหน้านั้นอยู่ ร้านขนาดปกติที่เปิดจอไว้ 2–3 เครื่องทั้งวันยังอยู่ในโควตาฟรี

ติดตั้ง Node.js 22 ขึ้นไป แล้วเปิด Terminal ในโฟลเดอร์นี้:

```bash
node test/local.js   # เปิดที่ http://localhost:8787  (PIN ทดลอง 123456 ข้อมูลหายเมื่อปิด)
npm test             # รันชุดทดสอบ
```
