# ระบบร้านอาหาร

ใช้บน iPad ผ่าน Safari ได้เลย และเปิดใช้บน **Cloudflare แบบฟรี**

## ทำอะไรได้แล้ว

**หน้าร้าน (ส่วนที่ 2)**
- **ผังโต๊ะ:** เห็นทุกโต๊ะในหน้าเดียว โต๊ะที่มีลูกค้าแสดงแพ็กเกจ จำนวนคน จำนวนรอบที่สั่ง และเวลาที่เหลือ (นับถอยหลังทุกวินาที) ใกล้หมดเวลาเป็นสีส้ม เกินเวลาเป็นสีแดง
- **เปิดโต๊ะ:** เลือกแพ็กเกจหรือ "สั่งตามเมนู" (ไม่ใช่บุฟเฟต์) ใส่จำนวนผู้ใหญ่/เด็ก ระบบคำนวณค่าบุฟเฟต์และเริ่มจับเวลา
- **สั่งอาหาร:** สลับ "ในแพ็กเกจ" กับ "สั่งเพิ่ม (คิดเงินแยก)" แตะ + ที่รูปอาหาร ใส่หมายเหตุรายจานได้ ระบบกันไม่ให้สั่งเกินจำนวนจานต่อรอบ สั่งของที่หมด หรือสั่งของนอกแพ็กเกจแบบฟรี
- **จอออเดอร์ (ครัว):** ออเดอร์ใหม่ → กำลังทำ → พร้อมเสิร์ฟ → เสิร์ฟแล้ว แสดงชัดว่ารายการไหน "สั่งเพิ่ม" และมีหมายเหตุอะไร
- **คิดเงิน / ปิดโต๊ะ:** สรุปค่าบุฟเฟต์ + รายการสั่งเพิ่ม ใส่ค่าปรับหรือส่วนลดได้ เลือกวิธีจ่าย (เงินสด PromptPay โอน อื่น ๆ) แล้วปิดโต๊ะ
- ยกเลิกรอบที่สั่งผิด หรือยกเลิกการเปิดโต๊ะที่เปิดผิด (ก่อนสั่งอาหาร) ได้

**ตั้งค่าร้าน (ส่วนที่ 1)**
- **เมนู:** เพิ่ม แก้ ลบ **ใส่รูปได้** (ระบบย่อรูปให้อัตโนมัติ) ตั้งราคาสั่งเพิ่ม สลับ "พร้อมขาย / หมด" เลือกว่าอยู่ในแพ็กเกจไหน
- **แพ็กเกจ:** ราคาผู้ใหญ่/เด็ก เวลาทาน จำนวนจานต่อรอบ รายการอาหารในแพ็กเกจ
- **ตั้งค่าโต๊ะ:** เพิ่มทีละโต๊ะหรือหลายโต๊ะพร้อมกัน (ลบโต๊ะที่มีลูกค้าอยู่ไม่ได้)
- **รหัส PIN** กันคนนอก กรอกผิด 5 ครั้งล็อก 5 นาที

**ตั้งค่า รายงาน และการพิมพ์ (ส่วนที่ 3)**
- **ตั้งค่าร้าน:** ชื่อร้าน, QR รับเงิน, ขนาดกระดาษ 58/80 มม., ข้อความท้ายบิล
- **QR รับเงิน เลือกได้ 2 แบบ** (แท็บ ตั้งค่า → QR รับเงิน)
  - **อัปโหลดรูป QR** เช่น QR ร้านจากแอป K SHOP: ตอนคิดเงินจะแสดงรูปนี้พร้อมยอดเงินตัวใหญ่ ลูกค้าสแกนแล้วกรอกยอดเอง (แนะนำให้ครอปเหลือเฉพาะตัว QR)
  - **สร้างจากเลข PromptPay:** QR มียอดเงินในตัว ลูกค้าไม่ต้องกรอกยอด
- **พิมพ์ใบสั่งครัว / ใบแจ้งยอด** ผ่านเบราว์เซอร์ (ใบแจ้งยอดพิมพ์ QR ได้ด้วย) และเปิด **"พิมพ์ออเดอร์ใหม่อัตโนมัติ"** ได้แยกเป็นรายเครื่องในหน้าออเดอร์
- **รายงานยอดขาย:** วันนี้ / เมื่อวาน / 7 วัน / เดือนนี้ หรือเลือกวันเอง ดูยอดรวม จำนวนบิล ลูกค้า แยกวิธีจ่าย รายวัน เมนูขายดี และรายการบิลทั้งหมด

**บอท LINE OA (ส่วนที่ 4)**
- **ตอบคำถามอัตโนมัติ:** ดูเมนู (การ์ดมีรูป), ราคาบุฟเฟต์, เวลาเปิด-ปิด ดึงจากข้อมูลจริงในระบบ คำถามอื่นใช้ AI ฟรีของ Cloudflare ตอบจากข้อมูลร้านเท่านั้น
- **สั่งกลับบ้าน:** ลูกค้ากดปุ่มในแชท → เลือกเมนูบนหน้าเว็บ → ร้านกด "รับออเดอร์" ในแท็บ LINE → เข้าจอครัวทันที และแจ้งลูกค้าทาง LINE
- **จองโต๊ะ:** ลูกค้ากรอกวัน เวลา จำนวนคน → ร้านกดยืนยัน/ปฏิเสธ → แจ้งลูกค้าทาง LINE
- **คุยกับพนักงาน:** ลูกค้ากดปุ่มแล้วบอทหยุดตอบ 1 ชั่วโมง ระบบแจ้งเตือนในแท็บ LINE (มีตัวเลขและเสียงเตือน) พนักงานตอบในแอป LINE OA

**ส่วนถัดไป:** ส่งงานพิมพ์ตรงถึงเครื่องพิมพ์ครัวโดยไม่ต้องมีหน้าต่างพิมพ์ (ขึ้นกับรุ่นเครื่องพิมพ์)

> หลายเครื่องใช้พร้อมกันได้ (เช่น iPad หน้าร้าน + แท็บเล็ตในครัว) หน้าผังโต๊ะและจอออเดอร์อัปเดตเองทุก 15 วินาที

## เชื่อม LINE OA

**ค่าใช้จ่าย:** บอทตอบลูกค้าด้วยการ "ตอบกลับ" ซึ่ง LINE ไม่นับโควตาข้อความ จึงใช้กับ LINE OA แพ็กเกจฟรีได้ ส่วนข้อความแจ้งผล (รับออเดอร์แล้ว / ยืนยันการจองแล้ว) เป็นการส่งหาลูกค้า **นับโควตาข้อความรายเดือนของแพ็กเกจ** ถ้าโควตาหมด ระบบยังทำงานต่อ แค่ไม่ได้ส่งแจ้งลูกค้า (จะขึ้นบอกในหน้าจอ)
AI ใช้ Cloudflare Workers AI โควตาฟรีรายวัน ถ้าเกิน บอทจะตอบข้อความสำรองพร้อมปุ่มแทน

1. **เปิด Messaging API:** ในแอปหรือเว็บ LINE Official Account Manager ไปที่ **ตั้งค่า → Messaging API → เปิดใช้งาน** (ระบบจะให้เลือกหรือสร้าง Provider)
2. **เอารหัส 2 ตัวจาก LINE Developers** (developers.line.biz → เลือก Channel ของร้าน)
   - แท็บ **Basic settings** → คัดลอก **Channel secret**
   - แท็บ **Messaging API** → ด้านล่างสุด **Channel access token** → กด **Issue** แล้วคัดลอก
3. **ใส่รหัสใน Cloudflare** (ที่เดียวกับ ADMIN_PIN: Worker → Settings → Variables and Secrets → Add แบบ **Secret**)
   - `LINE_CHANNEL_SECRET` = Channel secret
   - `LINE_CHANNEL_ACCESS_TOKEN` = Channel access token
4. **ตั้ง Webhook:** ใน LINE Developers แท็บ **Messaging API** → **Webhook URL** ใส่ลิงก์ที่แสดงในแท็บ LINE ของระบบ (ลงท้ายด้วย `/api/line/webhook`) → กด **Verify** ให้ขึ้น Success → เปิด **Use webhook**
5. **ตั้งการตอบกลับใน LINE OA Manager** (ตั้งค่า → การตอบกลับ)
   - **Webhook:** เปิด
   - **ข้อความตอบกลับอัตโนมัติ:** ปิด (ไม่อย่างนั้นลูกค้าจะได้คำตอบซ้ำสองชุด)
   - **แชท:** เปิด (ให้พนักงานตอบเองได้เมื่อลูกค้ากด "คุยกับพนักงาน")
6. **เปิด AI:** ไฟล์ `wrangler.toml` ชุดนี้มีบรรทัด `[ai]` เพิ่มมา ให้อัปโหลดทับ
   - ถ้าเคยใส่ `database_id` เองในไฟล์นี้ ให้เปิดไฟล์ใน GitHub แล้วเพิ่ม 2 บรรทัดนี้ท้ายไฟล์แทนการอัปโหลดทับ
     ```toml
     [ai]
     binding = "AI"
     ```
7. ไปที่แท็บ **LINE** ในระบบ ใส่เวลาเปิด-ปิด เบอร์โทร ที่อยู่ และข้อมูลอื่นที่อยากให้บอทตอบ แล้วกดบันทึก
8. ทดสอบ: ทักแชท LINE OA ของร้านด้วยมือถือ พิมพ์ "ดูเมนู" หรือ "ร้านเปิดกี่โมง"

## ลูกค้าสแกน QR สั่งอาหารที่โต๊ะ

- เปิดโต๊ะแล้วในหน้าสั่งอาหารกด **"QR ให้ลูกค้าสั่ง"** → ให้ลูกค้าสแกนจากจอ หรือกด **พิมพ์ QR** วางบนโต๊ะ (เครื่องที่เปิด "พิมพ์อัตโนมัติ" จะพิมพ์ QR ให้เองทุกครั้งที่เปิดโต๊ะ)
- ลูกค้าสั่งได้ทั้ง **บุฟเฟต์** (เฉพาะรายการในแพ็กเกจของโต๊ะ) และ **สั่งเพิ่ม** (คิดเงิน) ออเดอร์เข้าจอครัวทันที มีป้าย "ลูกค้าสั่งเอง"
- ลูกค้ากด **เรียกพนักงาน / เช็คบิล** ได้ → การ์ดโต๊ะบนผังโต๊ะขึ้นป้ายสีฟ้า มีเสียงเตือน (หายเมื่อพนักงานกดเข้าโต๊ะนั้น)
- หมดเวลาบุฟเฟต์แล้ว ลูกค้าสั่งรายการในแพ็กเกจเองไม่ได้ (สั่งเพิ่มแบบคิดเงินได้) พนักงานยังสั่งให้ได้ตามปกติ
- QR ใช้ได้เฉพาะรอบลูกค้านั้น ปิดบิลแล้วใช้ไม่ได้ ถ้า QR หลุดไปถึงคนอื่น กด "สร้าง QR ใหม่" ได้
- ปิดฟีเจอร์นี้ได้ที่ **ตั้งค่า → ข้อมูลร้าน**

## เสียงเตือน
- ออเดอร์ใหม่ที่ลูกค้าสั่งผ่าน QR → เสียง "ติ๊ง-ต่อง"
- ลูกค้ากดเรียกพนักงาน / ขอเช็คบิล → เสียงผู้หญิงพูด "ลูกค้าโต๊ะที่ 5 เรียกพนักงานค่ะ" / "ลูกค้าโต๊ะที่ 5 ขอเช็คบิลค่ะ"
- เปิด-ปิดและทดสอบเสียงได้ที่ ตั้งค่า → ข้อมูลร้าน → เสียงเตือน (ตั้งแยกแต่ละเครื่อง)
- เสียงพูดใช้เสียงภาษาไทยที่มีในเครื่อง: Microsoft Edge มีเสียงผู้หญิง Premwadee ให้เลย · Chrome บน Windows ต้องเพิ่มภาษาไทย (ติ๊ก Text-to-speech) ใน Settings → Time & language → Language & region ก่อน ถ้าไม่มีเสียงไทยจะใช้เสียงกริ๊งแทน
- หลังเปิดเครื่อง ให้แตะหน้าจอ 1 ครั้ง เบราว์เซอร์ถึงจะยอมเล่นเสียง และเปิดหน้าผังโต๊ะหรือออเดอร์ทิ้งไว้

## นำเข้าเมนูจากไฟล์ / ใส่รูปหลายรูป

- แท็บ **เมนู → นำเข้าจากไฟล์**: เลือกไฟล์ `.json` ที่เตรียมไว้ (เช่น ไฟล์ที่แปลงจากเมนู Food Story) ตรวจตารางสรุป แล้วกด "นำเข้า" เมนูที่ชื่อซ้ำจะอัปเดตราคา/หมวด ไม่สร้างซ้ำ นำเข้าซ้ำได้ปลอดภัย
- แท็บ **เมนู → ใส่รูปหลายรูป**: เลือกรูปทีละหลายไฟล์ ตั้งชื่อไฟล์ตามชื่อเมนู ระบบจะจับคู่ให้ ไฟล์ไหนจับคู่ไม่ได้ เลือกเมนูเองในตาราง

## การพิมพ์

ระบบสั่งพิมพ์ผ่านเบราว์เซอร์ จึงพิมพ์ได้กับเครื่องพิมพ์ที่เครื่องนั้นสั่งพิมพ์ได้อยู่แล้ว

### แนะนำ: คอมพิวเตอร์ Windows หน้าร้าน (จอสัมผัส) + Xprinter XP-58 แบบ LAN
1. **ติดตั้งเครื่องพิมพ์ใน Windows:** ลงไดรเวอร์ XP-58 (จากแผ่นที่มากับเครื่องหรือเว็บ Xprinter) แล้วเพิ่มเครื่องพิมพ์แบบ **TCP/IP** โดยใส่ IP ของเครื่องพิมพ์ (กดปุ่ม Feed ค้างตอนเปิดเครื่องจะพิมพ์ใบที่มี IP ออกมา) ตั้งขนาดกระดาษ 58 มม. และตั้งเป็น **เครื่องพิมพ์หลัก (Set as default)**
2. **ให้ Chrome พิมพ์ทันทีโดยไม่ถาม:** คลิกขวาที่ไอคอน Chrome → Properties → ช่อง Target เติมท้ายสุดว่า ` --kiosk-printing` (เว้นวรรคหน้าเครื่องหมาย --) → OK ปิด Chrome ทุกหน้าต่างแล้วเปิดใหม่จากไอคอนนี้
3. ในระบบ: **ตั้งค่า → ขนาดกระดาษ 58 มม.** แล้วบันทึก
4. ในระบบ: แท็บ **ออเดอร์ → ติ๊ก "พิมพ์ออเดอร์ใหม่อัตโนมัติบนเครื่องนี้"**
   - ออเดอร์ที่ส่งจากคอมเครื่องนี้ ใบสั่งครัวจะพิมพ์ทันทีที่กด "ส่งเข้าครัว"
   - ออเดอร์ที่ส่งจากเครื่องอื่น (เช่น iPad เดินรับออเดอร์) คอมจะพิมพ์ให้ภายในประมาณ 10–15 วินาที ถ้าคอมเปิดหน้า "ผังโต๊ะ" หรือ "ออเดอร์" ค้างไว้
   - ปุ่ม "พิมพ์ใบแจ้งยอด" ตอนคิดเงิน ก็พิมพ์ออกทันทีเช่นกัน

### iPad / Android
- **iPad:** พิมพ์ได้เฉพาะเครื่องพิมพ์ที่รองรับ AirPrint (XP-58 ไม่รองรับ)
- **Android:** ลงแอปบริการพิมพ์ เช่น RawBT แล้วเพิ่มเครื่องพิมพ์แบบ Network พิมพ์ได้แต่ต้องกดยืนยันทุกครั้ง

## ติดตั้งครั้งแรก

### ขั้นที่ 1: อัปเดตโค้ดใน GitHub

ชุดนี้เปลี่ยนจากเวอร์ชันก่อนหน้า ให้ทำดังนี้

1. เปิด repository `restaurant-system` ใน GitHub
2. **ลบไฟล์เก่าที่ไม่ใช้แล้ว:** คลิกไฟล์ `server.js` → กดปุ่ม `…` มุมขวาบน → **Delete file** → **Commit changes**
3. **อัปโหลดไฟล์ใหม่:** กลับไปหน้าแรกของ repo → **Add file → Upload files** → ลากไฟล์และโฟลเดอร์ทั้งหมดในโฟลเดอร์ `restaurant-system` ที่แตก zip แล้ว (`src`, `public`, `test`, `wrangler.toml`, `package.json`, `README.md`) → **Commit changes**

ไฟล์ชื่อเดิมจะถูกแทนที่ด้วยเวอร์ชันใหม่ให้เอง

### ขั้นที่ 2: เปิดใช้งานบน Cloudflare (ฟรี)

1. สมัครบัญชีที่ **dash.cloudflare.com** (แพ็กเกจฟรี)
2. ไปที่ **Workers & Pages** → **Create application** → กด **Get started** ตรง **Import a repository**
3. เชื่อมบัญชี GitHub แล้วเลือก repo `restaurant-system`
4. ตั้งชื่อโปรเจกต์เป็น **`restaurant-system`** (ต้องตรงกับชื่อใน `wrangler.toml` ไม่อย่างนั้นจะ deploy ไม่ผ่าน) คำสั่ง deploy ใช้ค่าเริ่มต้น `npx wrangler deploy` ได้เลย
5. กด **Save and Deploy** แล้วรอจนขึ้นว่าสำเร็จ
   - Cloudflare จะสร้างฐานข้อมูล D1 ชื่อ `restaurant-db` ให้อัตโนมัติ และระบบจะสร้างตารางเองตอนเปิดใช้ครั้งแรก
6. **ตั้งรหัส PIN:** เปิด Worker `restaurant-system` → **Settings** → **Variables and Secrets** → **Add**
   - Type: **Secret**
   - Name: `ADMIN_PIN`
   - Value: รหัสของร้าน **อย่างน้อย 6 หลัก**
   - กดบันทึก/Deploy
7. เปิดลิงก์ที่ลงท้ายด้วย `.workers.dev` บน iPad → ใส่ PIN

**ทำให้เหมือนแอปบน iPad:** เปิดลิงก์ใน Safari → กดปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**

### ถ้า deploy ไม่ผ่านเพราะเรื่องฐานข้อมูล (database)

การสร้างฐานข้อมูลอัตโนมัติยังเป็นฟีเจอร์ทดลองของ Cloudflare ถ้าไม่ผ่าน ให้สร้างเอง:

1. ในหน้า Cloudflare ไปที่ **Storage & Databases → D1** → **Create database** → ตั้งชื่อ `restaurant-db`
2. คัดลอก **Database ID** ที่ได้
3. ใน GitHub เปิดไฟล์ `wrangler.toml` → กดรูปดินสอเพื่อแก้ → เพิ่มบรรทัดนี้ใต้ `database_name = "restaurant-db"`
   ```toml
   database_id = "วาง-ID-ที่คัดลอกมา"
   ```
4. กด **Commit changes** แล้ว Cloudflare จะ deploy ใหม่ให้เอง

## ทุกครั้งที่ได้โค้ดเวอร์ชันใหม่

อัปโหลดไฟล์ที่เปลี่ยนไปทับใน GitHub แบบเดิม Cloudflare จะอัปเดตเว็บให้อัตโนมัติ ข้อมูลร้าน (เมนู รูป โต๊ะ) อยู่ในฐานข้อมูล D1 ไม่หาย

## ข้อจำกัดของแพ็กเกจฟรี

ฐานข้อมูล D1 แบบฟรี อ่านได้วันละ 5 ล้านแถว เขียนได้วันละ 100,000 แถว เก็บได้ 5 GB ร้านอาหารหนึ่งร้านใช้ไม่ถึง ถ้าเกิน ระบบจะใช้ไม่ได้ชั่วคราวจนถึง 7 โมงเช้า (เวลาไทย) แต่ข้อมูลไม่หาย

รูปเมนูถูกย่อเหลือประมาณ 10–100 KB ต่อรูป เก็บได้หลายหมื่นรูป

หน้าผังโต๊ะและจอออเดอร์ดึงข้อมูลใหม่ทุก 15 วินาที เฉพาะตอนเปิดหน้านั้นอยู่ ร้านขนาดปกติที่เปิดจอไว้ 2–3 เครื่องทั้งวันยังอยู่ในโควตาฟรี

## สำหรับคนที่อยากลองบนคอมพิวเตอร์ก่อน (ไม่บังคับ)

ติดตั้ง Node.js 22 ขึ้นไป แล้วเปิด Terminal ในโฟลเดอร์นี้:

```bash
node test/local.js   # เปิดที่ http://localhost:8787  (PIN ทดลอง 123456 ข้อมูลหายเมื่อปิด)
npm test             # รันชุดทดสอบ
```
