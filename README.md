# ระบบร้านอาหาร (ส่วนที่ 1: ตั้งค่าร้าน)

ส่วนแรกของระบบร้านที่เราทำเอง ใช้บน iPad ผ่านเบราว์เซอร์ Safari ได้เลย

**ส่วนนี้ทำอะไรได้แล้ว**
- **เมนู:** เพิ่ม แก้ ลบเมนู ตั้งราคาสั่งเพิ่ม (à la carte) กดสลับ "พร้อมขาย / หมด" และเลือกว่าเมนูอยู่ในแพ็กเกจบุฟเฟต์ไหน
- **แพ็กเกจ:** เพิ่มแพ็กเกจบุฟเฟต์เอง ตั้งราคาผู้ใหญ่/เด็ก เวลาทาน จำกัดจานต่อรอบ และเลือกรายการอาหารในแพ็กเกจ
- **โต๊ะ:** เพิ่มโต๊ะทีละโต๊ะหรือหลายโต๊ะพร้อมกัน แก้ชื่อ ที่นั่ง โซน
- มีรหัส PIN กันคนนอกเข้ามาแก้ข้อมูล

**ส่วนถัดไป** (ยังไม่มีในชุดนี้): ผังโต๊ะ + เปิดโต๊ะ, สั่งอาหาร, พิมพ์เข้าครัว, คิดเงิน, บอท LINE OA

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|---|---|
| `server.js` | เซิร์ฟเวอร์และฐานข้อมูล |
| `public/` | หน้าจอที่เปิดบน iPad (`index.html`, `app.js`, `style.css`) |
| `test/api.test.js` | ชุดทดสอบอัตโนมัติ |
| `package.json` | ข้อมูลโปรเจกต์และคำสั่งรัน |

ระบบนี้**ไม่ต้องติดตั้งแพ็กเกจเสริม** ใช้แค่ Node.js เวอร์ชัน 22.13 ขึ้นไป ฐานข้อมูลเป็นไฟล์เดียวชื่อ `restaurant.db` เก็บอยู่ในโฟลเดอร์ `data/`

## ขั้นที่ 1: นำโค้ดขึ้น GitHub (ทำผ่านเว็บได้)

1. สมัครหรือเข้าสู่ระบบที่ github.com
2. ไปที่ github.com/new ตั้งชื่อ repository เช่น `restaurant-system` แล้วเลือก **Private** เพื่อไม่ให้คนอื่นเห็นโค้ด จากนั้นกด **Create repository**
3. ในหน้า repository ใหม่ กดลิงก์ **uploading an existing file**
4. แตกไฟล์ zip ที่ได้รับ แล้วลาก**ไฟล์และโฟลเดอร์ทั้งหมดในโฟลเดอร์ `restaurant-system`** ไปวาง (ต้องมี `public` และ `test` ไปด้วย) แนะนำให้ใช้ Chrome บนคอมพิวเตอร์ เพราะลากทั้งโฟลเดอร์ได้
5. กด **Commit changes**

> ไฟล์ `.gitignore` ขึ้นต้นด้วยจุด บางเครื่องจะซ่อนไว้ ถ้าไม่ได้อัปโหลดไปก็ยังใช้งานได้ แต่ห้ามอัปโหลดโฟลเดอร์ `data/` ขึ้น GitHub

## ขั้นที่ 2: เปิดใช้งานบนอินเทอร์เน็ต (ตัวอย่าง: Railway)

ระบบต้องมี**พื้นที่เก็บข้อมูลถาวร** ไม่อย่างนั้นข้อมูลร้านจะหายทุกครั้งที่เซิร์ฟเวอร์รีสตาร์ต ตัวอย่างนี้ใช้ Railway ซึ่งรองรับเรื่องนี้ (มีค่าบริการรายเดือน ราคาและหน้าตาเมนูอาจเปลี่ยน เช็กที่ railway.com ก่อนสมัคร)

1. สมัคร Railway ด้วยบัญชี GitHub
2. สร้างโปรเจกต์ใหม่ เลือก **Deploy from GitHub repo** แล้วเลือก `restaurant-system`
3. ในบริการที่สร้างขึ้น เพิ่ม **Volume** (พื้นที่เก็บข้อมูลถาวร) และตั้งตำแหน่งเชื่อมต่อ (mount path) เป็น `/data`
4. ไปที่ **Variables** แล้วเพิ่ม:
   - `ADMIN_PIN` = รหัส PIN ของร้าน **ตั้งเองอย่างน้อย 6 หลัก อย่าใช้ 1234**
   - `DATA_DIR` = `/data`
5. ไปที่ **Settings → Networking** แล้วกดสร้างโดเมน (Generate Domain) จะได้ลิงก์เว็บของร้าน
6. เปิดลิงก์นั้นบน iPad แล้วใส่ PIN

**ทำให้เหมือนแอปบน iPad:** เปิดลิงก์ใน Safari → กดปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม (Add to Home Screen)**

## ทุกครั้งที่ได้โค้ดเวอร์ชันใหม่

อัปโหลดไฟล์ที่เปลี่ยนไปทับใน GitHub แบบเดิม (Add file → Upload files) Railway จะอัปเดตเว็บให้อัตโนมัติ และข้อมูลร้านใน Volume ยังอยู่ครบ

## สำหรับคนที่อยากลองบนคอมพิวเตอร์ก่อน (ไม่บังคับ)

ติดตั้ง Node.js 22 ขึ้นไปจาก nodejs.org แล้วเปิด Terminal ในโฟลเดอร์นี้:

```bash
npm start      # เปิดที่ http://localhost:3000 (PIN ทดลองคือ 1234)
npm test       # รันชุดทดสอบ
```

## ข้อควรรู้

- **สำรองข้อมูล:** ข้อมูลทั้งหมดอยู่ในไฟล์ `restaurant.db` ไฟล์เดียว ส่วนถัดไปจะเพิ่มปุ่มดาวน์โหลดไฟล์สำรอง
- **PIN:** ใครรู้ PIN ก็แก้ข้อมูลร้านได้ ถ้าพนักงานลาออก ให้เปลี่ยน `ADMIN_PIN` ใน Railway ระบบล็อก 5 นาทีถ้ากรอกผิด 5 ครั้ง
- **ราคา:** เก็บแบบสตางค์ จึงใส่ทศนิยมได้ เช่น 59.50 โดยไม่มีปัญหาปัดเศษ
